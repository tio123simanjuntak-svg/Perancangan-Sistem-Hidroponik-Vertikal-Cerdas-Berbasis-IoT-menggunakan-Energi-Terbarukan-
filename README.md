# Perancangan-Sistem-Hidroponik-Vertikal-Cerdas-Berbasis-IoT-menggunakan-Energi-Terbarukan-
Proyek ini merancang sistem hidroponik vertikal cerdas yang terintegrasi dengan teknologi Internet of Things (IoT) dan ditenagai oleh energi terbarukan. Tujuannya adalah menghadirkan solusi pertanian perkotaan yang efisien, hemat lahan, dan ramah lingkungan.
